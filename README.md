# 🤖 Agentic AI with LangGraph

A hands-on repository for learning and building **Agentic AI systems from scratch** using **Python, LangChain, and LangGraph**.

This repository focuses on understanding how AI agents work internally — from basic LLM workflows to **tool calling, memory, state management, RAG, and multi-step agentic workflows**.

## 🚀 What You'll Learn

* 🧠 LLM fundamentals
* 🔗 LangChain components and Runnables
* 🕸️ LangGraph fundamentals
* 🛠️ Tool calling and custom tools
* 🧩 Agent workflows
* 💾 State and memory management
* 📚 Retrieval-Augmented Generation (RAG)
* 🔄 Multi-step and conditional workflows
* 🤖 Building practical AI agents from scratch

## 🛠️ Tech Stack

* **Python**
* **LangChain**
* **LangGraph**
* **LLMs**
* **RAG**
* **Tool Calling**
* **Git & GitHub**

## 🎯 Goal

The goal of this repository is to build a strong practical understanding of **Agentic AI** by implementing concepts step by step rather than relying only on high-level abstractions.

> Learn the concepts → Build the components → Connect them → Build agents.
